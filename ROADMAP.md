# Roadmap

OpenProject is the authoritative planning system. This summary separates current commitments from proposals and does not assign release dates.

## Current Work

- **Confirmed:** Complete the publication and secret review for the initial Git history.
- **Confirmed:** Obtain approval before the first push to the private GitHub repository.
- **Confirmed:** Reconcile project history, work packages, version records, and reciprocal links in OpenProject.
- **Confirmed:** Decide whether the existing `1.0.0` build candidate should become a formal release.

## Proposed Next Release Scope

- Add automated coverage for malformed settings, path edge cases, reparse points, backup recovery, and file-encoding behaviour.
- Add a repeatable continuous-integration build and test workflow after publication.
- Produce a portable archive containing the executable and every emitted runtime dependency, plus extraction instructions and a SHA-256 checksum.
- Establish supported Windows versions and a compatibility-test matrix.
- Decide the licence, support model, security-reporting route, and release policy.

These items are proposals, not committed features or dates. A future version should be created only when its coherent deliverable scope is approved in OpenProject.

## Unscheduled Ideas

- Evaluate usability improvements from real user acceptance testing.
- Evaluate improved diff/review support before overwriting externally changed files.
- Evaluate stronger backup browsing and recovery assistance.

These ideas remain unassigned until requirements and acceptance criteria exist.
